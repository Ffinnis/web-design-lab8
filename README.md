# Лабораторная работа № 8

Два индикатора выполнения на React и чат на обычном JavaScript с тремя способами обмена сообщениями. HTTP-сервер и WebSocket-сервер работают в одном процессе Node.js.

## Запуск

Из корня проекта выполните:

```sh
npm ci
npm start
```

Откройте [чат](http://127.0.0.1:3000/) или [индикаторы](http://127.0.0.1:3000/progress.html). Для проверки чата откройте две вкладки, выберите один режим в обеих и отправьте сообщение из каждой. История хранится в памяти до перезапуска сервера.

## Исходный код

- [Компонент ProgressBar](src/progress.jsx) — независимые таймеры и повторный запуск.
- [Страница чата](public/index.html) и [клиент](public/chat.js) — форма, список сообщений и переключение между AJAX, Comet и WebSocket.
- [Сервер](server.js) — маршруты HTTP, ожидающие запросы long polling и рассылка по WebSocket.
